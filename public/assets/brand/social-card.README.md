# SANFOR social card

`social-card.png` is a 1200 × 630 composition for default Open Graph/Twitter previews.
Created on 13 September 2026 from the existing `logo.svg`, SANFOR site colors, the authored engineering identity, and locally installed Inter (font package license retained in its distribution).

The original logo geometry and earlier banner are unchanged. This is a deterministic HTML/CSS rendering, with no generated photography or new authorship claims.

Reproduce from the repository root after `npm ci`, with Chrome installed:

```sh
node scripts/render-social-card.mjs
```

Page-specific article/project covers override this default.
