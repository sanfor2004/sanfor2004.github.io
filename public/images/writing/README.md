# Writing image provenance

This directory contains article covers and supporting editorial images used by the Sanfor blog. Images are illustrations unless a post explicitly identifies an application screenshot.

## 2026-09-15 technical tutorial covers

The four WebP covers below were generated with OpenAI's built-in image-generation tool on 15 September 2026, reviewed for subject clarity and unwanted text or logos, then center-cropped and encoded at 1600 × 900 for web delivery. The generated PNG originals remain in the tool's local generated-image archive and are not part of the website.

Shared direction: a text-free, wide technical-blog cover; expressive ink-and-gouache sketching on tactile warm paper; dark brown linework, burnt-orange accents, muted blue-gray details, and safe margins for responsive cropping; no trademarks, product logos, readable interfaces, or watermarks.

### `cpp-discord-bot-dpp.webp`

Prompt subject: a small friendly mechanical messenger carrying blank speech bubbles between a terminal-like device and an abstract community network of connected people, illustrating a C++ Discord bot without reproducing Discord or DPP branding.

### `cmake-explained-for-beginners.webp`

Prompt subject: a welcoming blueprint workshop where source pages and header cards move through a central build machine and emerge as a reusable library block and an executable machine.

### `redis-internals.webp`

Prompt subject: an incoming signal passing through an event-loop mechanism into organized in-memory data structures, then branching to an append-only journal, snapshot storage, and a replica machine without using Redis branding or performance claims.

### `electron-nextjs-desktop-app.webp`

Prompt subject: a desktop application window shown as a layered cutaway, with a web-interface surface, guarded bridge, main-process machinery, and a bundle of packaged static pages, without reproducing Electron or Next.js branding.

These images are visual metaphors. They are not screenshots, architecture specifications, benchmark evidence, or substitutes for the technical explanations and accessible text in their articles.
